# Вакансии онлайн-школы «Пифагор»

Статический сайт для GitHub Pages: лендинг вакансии + пошаговая анкета кандидата (3 шага), в стиле [pifagor.by](https://pifagor.by/).

## Адреса (ЧПУ)

| Страница | Путь |
|---|---|
| Список вакансий | `/` |
| Менеджер по контролю качества | `/vakansii/menedzher-po-kontrolyu-kachestva/` |
| Согласие на обработку ПД | `/soglasie/` |

Ссылку для Instagram удобно давать с меткой: `…/vakansii/menedzher-po-kontrolyu-kachestva/?utm_source=instagram` — источник попадёт в анкету.

## Куда приходят анкеты

Настройки — в начале файла `assets/app.js` (`CONFIG`). Анкета уходит сразу по двум каналам; достаточно, чтобы сработал один:

1. **Почта `pifagor.by@gmail.com`** через FormSubmit (бесплатно, без регистрации). После **первой** отправки на почту придёт письмо «Action required: Activate form» — нажмите кнопку активации один раз, после этого все анкеты приходят письмами-таблицами.
2. **CRM личного кабинета** (`backend-pifagor`, раздел «Заявки с сайта») — POST `/api/v1/requests`. Сработает, когда домен GitHub Pages добавлен в разрешённые CORS-origins бэкенда, например:
   ```python
   allow_origins=[..., "https://nikolajcikstas.github.io"]
   ```
   В заявке в поле «сообщение» первой строкой стоит «Вакансия: Менеджер по контролю качества», так что её легко отличить от заявок учеников.

Если оба канала недоступны, кандидат увидит кнопку «отправить письмом» с уже подставленными ответами.

## Новая вакансия

Скопируйте папку `vakansii/menedzher-po-kontrolyu-kachestva/` в `vakansii/<slug-latinicej>/`, поменяйте тексты и атрибут `data-vacancy` у формы, добавьте карточку в корневой `index.html`.

## Деплой

Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
